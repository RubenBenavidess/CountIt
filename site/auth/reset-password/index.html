Abre este enlace desde tu teléfono

Para crear una nueva contraseña, abre este enlace en el teléfono que tiene Count It! instalado.

Por tu seguridad, la contraseña solo se puede cambiar dentro de la app. Si el enlace venció, pide uno nuevo desde «¿Olvidaste tu contraseña?» en Count It!.

No compartas este enlace con nadie.
